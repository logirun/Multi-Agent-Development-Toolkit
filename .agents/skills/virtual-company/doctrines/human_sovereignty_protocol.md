# AegisFlow 人类操作员终审主权公约 (human_sovereignty_protocol.md)

> **“机器负责构建与验证确定性，人类执掌最终价值裁决”**  
> —— 本公约界定了 AegisFlow 神盾微内核中智能体执行集群与人类操作员之间的核心权责边界。

---

## 1. 人机职责分界矩阵

| 工程维度 | AI 智能体执行集群职能 | 人类操作员专属主权 |
| :--- | :--- | :--- |
| **业务意图** | 意图解析、风险网关评估 (L0-L3)、WBS 任务拆解 | 业务需求确立、技术路线方向裁定、验收标准制定 |
| **代码生产** | 接口契约生成、代码编写、AST 语法快筛、自动化单测 | 涉及核心破坏性重构、生产环境配置修改准入 |
| **门禁裁定** | 四维正交一票否决（QR/SR/FR/DR）、密码学收据签发 | 疑难争议裁决、一票否决豁免审查 |
| **异常恢复** | 停滞超期监控、三阶熔断阻断上报 | 熔断工单仲裁决策、时空回退目标检查点确认 |
| **最终交付** | 交付全量代码、全套测试、架构地图与密码学收据 | **Gate 6 终审验收（强制物理终端键盘交互确认，严禁代行）** |

---

## 2. 终端信息防 Token 膨胀保护 (Top-5 节流规范)

在控制台呈现与跨 Agent 上下文传递中，必须贯彻极简主义以控制上下文消耗：
1. **控制台看板渲染**：默认仅输出处于最前列的 5 项活跃任务；历史履历只追溯最近 5 次流转。需要观察全量时，显式传入 `--all` 或开启离线 Web 看板（`vc-cli web`）。
2. **跨智能体协作**：父级 Agent 派发任务时，仅传递任务卡号、所属风险级别、契约文件路径及具体 SOP 执行指令。子 Agent 通过本地文件读取按需拉取上下文，杜绝全量历史转储。

---

## 3. 人类物理终审验收操作准则 (Gate 6)

工单通过 Gate 1 至 Gate 5 全部前置门禁并获得完整密码学收据后，智能体停机并提请人类在控制台进行物理验收：

```bash
# 人类操作员在终端交互执行
python tools/vc_cli.py accept --id TSK-xxxx --by "张工 (系统架构负责人)" --note "Staging 环境测试全通，允许合入主干"
```

- **物理终端保护**：CLI 内置 `sys.stdin.isatty()` 校验，在缺少标准输入终端的脚本管道或自动化调度中自动终止并报错。
- **终态不可逆**：验收通过后工单标记为 `ACCEPTED`，状态机立即封板，严禁任何二次修改或状态倒流。
